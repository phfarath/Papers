# p13 — Mem0 (+ Mem0g) (arXiv 2504.19413)

## Português

Replicação offline do pipeline do **Mem0**: na extração, o prompt junta
(resumo corrente, **últimas 10 mensagens**, par novo user/assistant) e emite
fatos; na **update phase**, os **top-10** fatos similares são recuperados e
o LLM escolhe **ADD / UPDATE / DELETE / NOOP** para cada fato.
**Mem0g** é a variante em grafo: fatos viram arestas
(sujeito, relação, objeto) e conflitos **invalidam** a aresta antiga sem
apagá-la.

Métricas do paper reportadas no RESULTS: **latência** (wall time por query)
e **tokens-em-contexto** por query, além de acurácia via `qa.judge`.
`adapter.py` expõe `MemorySystem` (Mem0 e Mem0g) no registry compartilhado.

### Mapeamento paper → código

| Paper | Código |
|---|---|
| §3.1 extração com (summary, last-10, novo par) | `mem0.extract` + `_ingest_pair` |
| §3.2 update phase top-10 similar + ADD/UPDATE/DELETE/NOOP | `mem0.ops` + `_apply_ops` |
| §4 Mem0g grafo com invalidação por conflito | `Mem0gMemory` (`Triple.valid`) |
| latência + tokens-in-context | `MemStats`, `run._eval` |

### Rodar / Run

```bash
python -m papers.p13_mem0.run --seed 0 --write-results
```

## English

Offline replication of the **Mem0** pipeline: extraction consumes (current
summary, **last 10 messages**, new user/assistant pair) → facts; the
**update phase** retrieves **top-10** similar memories and the LLM picks
**ADD / UPDATE / DELETE / NOOP** per fact. **Mem0g** is the graph variant —
facts become (subject, relation, object) edges and conflicts **invalidate**
the old edge without deleting it. RESULTS reports the paper's metrics:
per-query **latency** and **tokens-in-context**, plus `qa.judge` accuracy.
Both variants ship `MemorySystem` adapters in the shared registry. Results
are generated by `run.py --write-results`.

## Resultados / Results

PT: o Mem0 obteve **0.50** geral (1.00 multi-hop, 1.00 update) — o melhor
dos sistemas treinados, acima do BM25 (0.44); ~37 tokens em contexto por
query vs ~1419 do oráculo. O Mem0g (grafo) agora recupera por entidade+slot com
arestas invalidadas renderizadas com intervalos — **0.88** geral,
1.00 temporal.

EN: Mem0 reached **0.50** overall (1.00 multi-hop, 1.00 update) — the best
trained system, above BM25 (0.44); ~37 tokens-in-context per query vs the
oracle's ~1419. Mem0g (graph) now retrieves by entity+slot with
invalidated edges rendered with intervals — **0.88** overall, 1.00
temporal.

**Nota didática / Didactic note:** Mem0's UPDATE/DELETE drops old values —
it cannot answer "what was my previous job?" (temporal 0.00). Zep (p12)
keeps them as closed intervals and scores 1.00 temporal — a real design
contrast, not a bug.

O UPDATE/DELETE do Mem0 descarta valores antigos — não responde "qual era
meu emprego anterior?" (temporal 0.00). O Zep (p12) os mantém como
intervalos fechados e acerta 1.00 em temporal.

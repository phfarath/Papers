# p12 — Zep / Graphiti (arXiv 2501.13956)

## Português

Replicação offline do mecanismo do **Zep/Graphiti**: um **grafo temporal
bitemporal** onde cada aresta (fato) carrega `t_valid`/`t_invalid` (tempo de
mundo) e `t_created`/`t_expired` (tempo de transação). Contradições **não
apagam** a aresta antiga — recebem `t_invalid` (edge invalidation). A busca é
híbrida: **cosine + BM25 + BFS no grafo**, fundidos por **RRF**, com opção
**MMR** para diversidade. O contexto entregue é uma string com **intervalos
de validade** (`valid: date → date/present`).

Extração de fatos e detecção de contradição/retratação são heurísticas
offline (slots: city, job, pet, breakfast, hobby; "gave it away" invalida o
pet). `adapter.py` expõe `MemorySystem` e está no registry compartilhado.

### Mapeamento paper → código

| Paper | Código |


## English

Offline replication of **Zep/Graphiti**: a **bitemporal temporal graph**
whose edges carry `t_valid`/`t_invalid` (world time) and
`t_created`/`t_expired` (transaction time). Contradictions **invalidate** the
old edge (`t_invalid` set) rather than deleting it. Hybrid search = **cosine
+ BM25 + BFS** fused by **RRF**, with an optional **MMR** diversification
pass. The delivered context is a string with **validity ranges**. Fact
extraction and contradiction/retraction detection are offline heuristics.
Includes a `MemorySystem` adapter in the shared registry. Results are
generated by `run.py --write-results`.

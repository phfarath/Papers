# p08 — CoALA (arXiv 2309.02427)

## Português

Replicação offline do **framework CoALA** (Cognitive Architectures for
Language Agents) — ao contrário dos outros papers, CoALA é uma *taxonomia*, e
a réplica tem duas partes:

1. **Um agente CoALA** no HouseholdEnv com os quatro tipos de memória e o
   ciclo de decisão do paper (§3):
   - *Working memory* (`WorkingMemory`): tarefa corrente + plano + ações
     recentes.
   - *Long-term memory*: **episodic** (notas de episódios) + **semantic**
     (regras "you should heat X with the microwave" /
     "X does not contribute") — procedural é representada pelas rotinas do
     próprio agente.
   - *Internal actions*: `reason` (atualiza a WM via `coala.reason`),
     `retrieve` (lê a LTM via `coala.retrieve`), `learn` (escreve na LTM via
     `coala.learn`, no fim do episódio).
   - *External actions*: as ações do env (grounding).
   - *Decision cycle*: planning = **propose** (ações válidas) → **evaluate**
     (`score_actions` com a memória) → **select** (argmax) → execute.
2. **A taxonomia aplicada ao próprio repo** (`taxonomy.py`): `describe()`
   classifica todos os módulos p01–p18 (incluindo os ainda não implementados,
   por nome) nas dimensões CoALA — tipos de memória, espaço de ações,
   procedimento de decisão — renderizada como tabela no RESULTS.md.

### Mapeamento paper → código

| Paper | Código |
|---|---|
| §3.1 memory stores (working/episodic/semantic/procedural) | `WorkingMemory`, `LongTermMemory` em `method.py` |
| §3.2 internal actions (reasoning, retrieval, learning) | `_internal_reason/_internal_retrieve/_internal_learn` |
| §3.2 external grounding actions | `env.step(act)` em `CoALAAgent.run_episode` |
| §3.3 decision cycle (planning: propose→evaluate→select) | `CoALAAgent._select` + loop |
| Tabela 1 (taxonomy of agents) | `taxonomy.py::describe()` + tabela no RESULTS |

### Honestidade / desvios

- O bug interessante que o paper ilustra: notas episódicas com a palavra
  "failure" eram interpretadas como *conselho ruim* pelo avaliador — a nota
  foi reformulada de forma neutra e lições negativas agora só são escritas
  quando o env explicitamente rejeita a ação ("cannot ...").
- Resultado honesto: neste env pequeno o ganho do CoALA sobre ReAct é
  modesto (a tabela mostra os números reais; nada foi ajustado para forçar
  vitória).

### Rodar / Run

```bash
python -m papers.p08_coala.run --seed 0 --write-results
```

## English

Offline replication of the **CoALA** framework — a taxonomy paper, so the
replication has two parts: (1) a **CoALA-style agent** on HouseholdEnv with
working + episodic + semantic memories (procedural represented by the
agent's routines), internal actions (reason → update WM; retrieve → read
LTM; learn → write LTM) vs external grounding actions, and the decision
cycle planning = propose → evaluate → select → execute; (2) the **taxonomy
itself applied to this repo** — `taxonomy.describe()` classifies all p01–p18
modules (including not-yet-implemented ones by name) by CoALA dimensions,
rendered as a table in RESULTS.md.

Fidelity note: episodic notes were rephrased to be neutral after we found
the word "failure" was being scored as bad advice, and negative semantic
lessons are now only written when the env explicitly rejects an action.

Results are generated by `run.py --write-results` at a fixed seed — never
hand-written, and not the paper's numbers.

# p09 — Generative Agents (arXiv 2304.03442)

## Português

Replicação offline do mecanismo dos **Generative Agents** num
**Mini-Smallville** de 4 agentes com ticks de 1 hora: cada agente tem um
*memory stream*, planeja o dia (day plan → agenda por hora → passo de 5–15
min), reage, conversa — e medimos a **difusão da informação** ("convite para
a festa") pela população, como o experimento do paper.

### Mapeamento paper → código

| Paper | Código |
|---|---|
| Memory stream (obs/reflection/plan) | `Memory`, `MemoryStream` em `method.py` |
| Retrieval = recency + importance + relevance, pesos 1, min-max | `MemoryStream.retrieve` |
| Recency decay 0.995/hora | `RECENCY_DECAY` |
| Importância 1–10 | handler `ga.importance` |
| Reflexão quando importância acumulada >150 | `Agent.maybe_reflect` (`REFLECT_THRESHOLD`) |
| 3 perguntas sobre as últimas ~100 memórias | `ga.reflect_q` (`REFLECT_LAST_N=100`, `N_QUESTIONS=3`) |
| 5 insights com citações (mem-ids) | `ga.insight` (`N_INSIGHTS=5`) |
| Planejamento (day → hourly → 5–15 min) | `ga.plan`, `Agent.plan` |
| Difusão da informação (party invitation) | `Smallville.tick`, `run_simulation` |
| Ablações sem reflexão / sem planejamento | `run.py` |

### Honestidade / desvios

- O resultado é honesto: **planejamento** acelera visivelmente a difusão
  (agentes saem e se encontram mais); **reflexão** é neutra na velocidade de
  difusão neste toy — as reflexões são geradas e guardadas (contadas em
  teste), mas não mudam a taxa de encontro. Reportado como está.
- O número de insights é ≤1 por pergunta nesta implementação (paper pede 5
  por questão total; geramos 5 no handler e guardamos 1 por pergunta para
  manter o run rápido).

### Rodar / Run

```bash
python -m papers.p09_generative_agents.run --seed 0 --write-results
```

## English

Offline replication of the **Generative Agents** mechanism on a 4-agent
**Mini-Smallville** with hourly ticks: per-agent memory streams
(obs/reflection/plan), retrieval scored as `recency·0.995^hours +
importance(1–10) + relevance` (all weights 1, min-max normalized),
reflection triggered when cumulative importance >150 (3 questions over the
last ~100 memories → cited insights stored back), hierarchical planning
(day → hourly → 5–15 min), reaction and dialogue. The run measures
**information diffusion** (a party invitation) and includes no-reflection /
no-planning ablations as in the paper.

Honesty note: planning visibly accelerates diffusion; reflection is neutral
in this toy (insights are generated and stored — covered by tests — but do
not change encounter rates). Results are generated by
`run.py --write-results`, never hand-written.

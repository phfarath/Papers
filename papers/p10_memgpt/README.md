# p10 — MemGPT (arXiv 2310.08560)

## Português

Replicação offline do mecanismo do **MemGPT** sobre o dataset conversacional
compartilhado (`papers/common/conv_data.py`). Memória em camadas tipo SO:

- **Core memory** — blocos `persona`/`human` com limite de caracteres, sempre
  no contexto.
- **Recall memory** — FIFO da conversa.
- **Archival memory** — store vetorial paginável (VectorIndex).

O agente opera por **chamadas de função** — as 7 do paper
(`send_message`, `core_memory_append`, `core_memory_replace`,
`archival_memory_insert`, `archival_memory_search`,
`recall_memory_search`, `heartbeat`) — com **heartbeat chaining** (até 3
turnos encadeados). Pressão de contexto: **warning a 70%** e **flush a
100%**, descartando ~50% das mensagens FIFO mais antigas num **resumo
recursivo** (resumo anterior + metade antiga → novo resumo).

O `adapter.py` expõe um `MemorySystem` compatível (reset/add/retrieve) para
os benchmarks do batch 4; o registry `papers/common/adapters.py` o inclui.

### Mapeamento paper → código

| Paper | Código |
|---|---|
| Fig. memória em camadas (core/recall/archival) | `CoreBlock`, `fifo`, `archival` em `MemGPTAgent` |
| 7 function calls (Tab. 1) | `FUNCTIONS` + `MemGPTAgent.call` |
| Heartbeat chaining | loop em `MemGPTAgent.step` (`MAX_HEARTBEATS`) |
| 70% warning / 100% flush / ~50% evict + resumo recursivo | `_maybe_flush`, `memgpt.summarize` |

### Honestidade / desvios

- `memgpt.step` é um dispatcher heurístico (fatos→archival, perguntas→search)
  que emite chamadas em texto; as funções são executadas de verdade.
- A avaliação usa o dataset sintético compartilhado e `qa.judge`; os números
  são gerados, não os do paper.

### Rodar / Run

```bash
python -m papers.p10_memgpt.run --seed 0 --write-results
```

## English

Offline replication of the **MemGPT** mechanism on the shared conversational
dataset. OS-style layered memory — **core** (persona/human blocks with char
limits, always in context), **recall** (conversation FIFO), **archival**
(paged vector store) — driven by the paper's **7 function calls** with
heartbeat chaining, **70% context warning** and **100% flush** that evicts
~50% of the oldest FIFO messages via recursive summarization. `adapter.py`
exposes a `MemorySystem`-conforming interface used by the shared registry
for batch-4 benchmarks.

Results are generated by `run.py --write-results` at a fixed seed — never
hand-written, and not the paper's numbers.
